# Milestone 6 findings (2026-11-01)

- A `nuaged` built on Ubuntu 26.04 needs glibc 2.43: it would not run on Ubuntu 24.04 (2.39) or Debian 12 (2.36).
  The native packages use `x86_64-unknown-linux-musl` static binaries instead.
- reqwest with rustls failed in a minimal container ("builder error": no system certificates). Nuage only talks
  plain HTTP to rclone on 127.0.0.1, so TLS was removed altogether; with it went `ring`, the only C code of the build,
  and the need for `musl-gcc`.
- The static `nuaged` passes the end-to-end tests (rclone, `nuage-fs`, sign-in), and the `.deb` installs and mounts a
  `local` account in clean Ubuntu 24.04 and Debian 12 containers (`--device /dev/fuse --cap-add SYS_ADMIN`).
- Without D-Bus (containers, servers), `oo7` fails at once ("No such file or directory" on the bus socket): the
  daemon falls back to a plain `rclone.conf` in mode 0600, as intended.
- The rclone release archive has no license file: `scripts/fetch-rclone.sh` fetches `COPYING` at the same tag and the
  packages ship it as `rclone-COPYING`.
- Not checked: `loginctl enable-linger` and a reboot of a real server (needs a machine to reboot).
